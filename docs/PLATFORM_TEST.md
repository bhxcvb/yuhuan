# 平台测试清单

每次发版前按此清单人工过一遍。代码检查只能覆盖逻辑，覆盖不到真机行为。

## Android

- [ ] 全新安装，桌面图标名称与图标正确
- [ ] 覆盖安装后进度保留
- [ ] 首页 → 今日学习 → 答题 → 解析 → 返回，不跳错页面
- [ ] 系统返回键：练习中返回上一层，首页返回退出
- [ ] 阅读/七选五整篇作答，交卷后才出译文
- [ ] 长按单词弹卡片，可加入生词本
- [ ] 朗读按钮有声音（依赖系统 TTS）
- [ ] 断网点「开始今日学习」仍可用

## iPhone / iPad（PWA）

- [ ] Safari 打开网页版 → 添加到主屏幕，图标和名称正确
- [ ] 主屏幕打开后全屏、无地址栏
- [ ] 飞行模式下重新打开仍能做题
- [ ] 锁屏后再打开，进度在

## iPhone / iPad（WKWebView 原生壳，重点）

> v6.24 已做代码层加固，但当前审计环境是 Android，**以下条目尚未在真机验证**，发版前需在 Mac + iPhone 上过一遍。

- [ ] 安全区：刘海屏 / 灵动岛机型，顶部标题不被遮挡，底部导航不被 Home Indicator 压住
- [ ] `dvh`：展开/收起 Safari 工具栏后，底部导航始终在屏幕内（v6.24 用 `calc(100dvh / var(--fs))` + `100vh` 回退）
- [ ] 字号：标准 / 大 / 特大三档切换后，底部导航仍可见、页面无横向滚动（v6.24 改为 CSS 变量 + 高度补偿）
- [ ] 语音：点朗读在**用户手势内**触发；系统无英文语音时提示，而非静默失败；朗读中途切后台再回来能停止
- [ ] 键盘：点查词/导入输入框时，输入框自动滚到键盘上方不被遮挡
- [ ] 滚动：长页面（答案解析、范文）惯性滚动流畅，`-webkit-overflow-scrolling` 生效
- [ ] 长按取词：在英文正文上长按 0.5s 弹出词卡；在中文/空白处长按给出提示
- [ ] 返回手势：练习中侧滑返回不丢已答记录（答题即保存）
- [ ] 文件导入：从「文件」App 选择进度 JSON/题库 JSON 能读取
- [ ] 数据持久化：杀掉 App 再打开、覆盖安装后进度仍在

## Windows

- [ ] Edge 安装为应用，开始菜单可见
- [ ] 独立包：解压双击 `语欢.exe` 能启动
- [ ] 窗口缩放后布局不错乱
- [ ] 数据在重启后保留
