## 修复清单（按严重程度）

### P0 数据安全 / 阻断级

1. 本地数据解析失败会静默清零 → 现在会先保留损坏副本，并检测 IndexedDB 自动备份、询问是否恢复。
2. 导入/恢复不做结构规范化 → 新增 `normalizeStore()`，加载、导入、备份恢复、撤销统一走规范化，残缺/旧数据不会崩溃。
3. 清空进度/清空错题不可撤销 → 操作前自动备份，备份失败会取消。
4. 题库导入无校验/无备份/无入口 → 补齐入口（导出/导入/恢复内置/撤销），导入前校验结构与存储容量，写入失败回滚。
5. PWA 永远停在旧版本（cache-first + 固定缓存名）→ 导航请求 network-first，静态资源 stale-while-revalidate，缓存版本化。
6. 备份形态脆弱 → 进度备份剥离自定义题库、支持保存为文件/从文件导入；自动备份带时间戳；恢复前自动备份当前数据。

### P1 功能 / 逻辑

1. 薄弱点用「覆盖率」冒充正确率 → 改为真实正确率（`pointStats`），掌握度 = 正确率 70% + 覆盖度 30%。
2. 间隔复习固定阶梯、掌握后直接删除记录 → 动态因子（正确率、遗忘次数、错因）+ 掌握后保留 60–120 天长间隔。
3. 首页建议/摸底结果/学习分析沿用错误口径 → 全部改用真实数据。
4. 无针对性推荐 → 新增「推荐练习」：到期复习 → 薄弱知识点 → 新题补足。
5. 错题无智能分类 → 按错因 + 知识点历史正确率自动归类（概念不清/粗心/没看懂句子/未归因）。
6. 每周目标字段无 UI、周报信息量不足 → 设置页可调每周目标；周报包含目标完成度、环比、错题分类、薄弱点 Top3、下周建议。
7. 题库导入/导出是死代码 → 补 UI 与安全校验。
8. 桌面端副本停留在 v6.9 → 构建时同步（副本不入库）。
9. 校验器误报 117 条 → 修正七选五译文与范文校验口径（现 33 条，均为运行时隐藏的重复题）。
10. 重复题判定漏判 7 组 → 题干占位符归一化后隐藏。
11. 单题池兜底可能混入篇章题 → 已排除；「复习篇章」可随机复习到期篇目。

### P2 UI / 兼容 / 性能

- 特大字号把底部导航挤出屏幕 → 高度补偿后各视口正常。
- 网页版缺 `reward.webp` 导致裂图 → 补齐并纳入 SW 缓存/构建。
- 复制改用 `navigator.clipboard` + 回退；toast 层级提高；长按取词增加 `caretPositionFromPoint` 回退。
- 主题色适配（`color-mix` 带回退）、按钮/标签触控尺寸、提示字号、焦点样式、减少动效支持。
- 双空题选项（含 `;`）增加说明。

## 题库审计结论

- **无高严重度数据问题**：答案越界、选项数异常、选项重复、空字段、解析过短、知识点不存在、篇章译文缺失、渲染破坏字符均为 0。
- 中等问题：7 组用户可见重复题（已修复）；45 道模块基础题无知识点字段（按设计保留，已写入 README 数据口径）；部分模块答案位置偏 A（不改答案/选项顺序，避免破坏译文对应关系）。

## 遗留风险 / 后续建议

- 真机（尤其 iOS）未验证：`zoom` + `dvh`、安全区、Safari 语音合成。
- `render()` 仍是单个大函数；新增页面建议按 `phase` 拆分，避免继续膨胀。
- 自定义题库与内置题库共用一套进度索引，切换题库时旧进度可能对不上（导入提示已说明，后续可考虑按题库隔离进度）。
- `viewport` 禁用了缩放（可访问性取舍）；可评估改为允许缩放 + `touch-action` 防误触。
