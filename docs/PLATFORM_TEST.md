# 平台测试清单

每次发版前按此清单人工过一遍。代码检查只能覆盖逻辑，覆盖不到真机行为。

## Android

- [ ] 全新安装，桌面图标名称与图标正确
- [ ] 覆盖安装后进度保留
- [ ] 首页 → 今日学习 → 答题 → 解析 → 返回，不跳错页面
- [ ] 系统返回键：练习中返回上一层，首页返回退出
- [ ] 阅读/七选五整篇作答，交卷后才出译文
- [ ] 长按单词弹卡片，可加入生词本
- [ ] 朗读按钮有声音（依赖系统 TTS）
- [ ] 断网点「开始今日学习」仍可用

## iPhone / iPad（PWA）

- [ ] Safari 打开网页版 → 添加到主屏幕，图标和名称正确
- [ ] 主屏幕打开后全屏、无地址栏
- [ ] 飞行模式下重新打开仍能做题
- [ ] 锁屏后再打开，进度在

## Windows

- [ ] Edge 安装为应用，开始菜单可见
- [ ] 独立包：解压双击 `语欢.exe` 能启动
- [ ] 窗口缩放后布局不错乱
- [ ] 数据在重启后保留

## 浏览器（桌面）

- [ ] Chrome / Edge / Firefox / Safari 各打开一次
- [ ] 字号调节（标准/大/特大）生效且不溢出
- [ ] 备份导出 → 清空 → 导入，进度一致

## 数据相关

- [ ] 导出 JSON 含题库进度、错题、生词、成就
- [ ] 自动备份恢复（我的 → 从自动备份恢复）
